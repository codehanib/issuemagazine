# 📘 ISSUE MAGAZINE
Spring Boot를 활용한 전자잡지 웹사이트 팀 프로젝트입니다.

## 프로젝트 소개
다양한 잡지를 온라인에서 조회하고 구매할 수 있는 전자잡지 쇼핑몰을 구현한 프로젝트입니다.

회원은 상품 조회 및 구매, 장바구니, 주문과 주문 내역 조회, 위시리스트, 1:1 문의와 후기 작성<br>
관리자는 회원, 상품, 주문, 배송, 공지사항 등을 관리

- 개발 기간 : 2026.08.10 ~ 2026.08.19

## 추가 개선 사항
### 주문 취소 방식 개선 - 김은진(KEJ)

프로젝트 종료 후 기존 기능에서 개선이 필요하다고 생각한 부분을 개인적으로 추가 수정했습니다.

기존에는 주문 취소 시 해당 주문 데이터를 DB에서 삭제하도록 구현되어 있어 취소된 주문의 이력이 남지 않는 문제가 있었습니다.
이를 개선하여 주문 데이터를 삭제하지 않고 `o_status`를 `주문취소` 상태로 변경하도록 수정했습니다.

**기존 방식**
```sql
DELETE FROM orders
WHERE o_no = #{o_no}
  AND m_no = #{m_no}
```

**개선 방식**
```sql
UPDATE orders
SET o_status = '주문취소'
WHERE o_no = #{o_no}
  AND m_no = #{m_no}
```
